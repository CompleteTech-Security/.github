## About

Organization profile and default community health files for CompleteTech Security. Files here apply to every repository in the organization that does not have its own copy.

## Files

| File | Purpose |
|---|---|
| `profile/README.md` | The organization profile page |
| `CONTRIBUTING.md` | How to contribute |
| `SUPPORT.md` | Where to get help |
| `SECURITY.md` | How to report a vulnerability |
| `CODE_OF_CONDUCT.md` | Community standards |
| `.github/ISSUE_TEMPLATE/` | Default bug and feature issue forms |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template |
| `labels.yml` | The estate label set applied to every repository |
| `LICENSE` | MIT license for the templates |
